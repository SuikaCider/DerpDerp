# prompts/

Copy-paste prompts for when you get stuck.

- **[`ask-llm-for-help.md`](ask-llm-for-help.md)** — a ready-made briefing you can paste
  into any AI assistant (ChatGPT, Claude, Gemini, etc.) so it can walk you through
  installing, configuring, or debugging this tool. Paste it, then add your specific
  question or error at the bottom.

This tool's actual *answer* prompt (the instructions the model follows when you ask it
something) is **not** here — it lives inline in `derpderp.py` as the `SYSTEM` string, so
it ships as part of the one file.
